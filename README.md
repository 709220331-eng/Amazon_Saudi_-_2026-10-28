# Amazon Saudi Operations

Amazon.sa 沙特站经营数据库网页原型。

## 当前版本
- Next.js + TypeScript
- 适配桌面端与移动端
- 支持在浏览器中读取 Excel / CSV
- 识别并跳过以“旧档_”开头的归档工作表
- 展示产品、订单、广告、库存工作表预览
- 货币展示使用 SAR

## 当前限制
这是第一版前端原型，不是正式账务系统。当前导入文件仅在浏览器会话中解析，不会写入云数据库或自动同步设备。刷新后需要重新导入。指标是按工作簿中匹配的字段做基础汇总，尚未完成利润、VAT、结算差异等完整业务计算。

## 本地运行
需要安装 Node.js 20 或更高版本。

```bash
npm install
npm run dev
```

打开终端提示的本地地址（通常为 http://localhost:3000）。

## Vercel 部署
将仓库导入 Vercel，框架选择 Next.js，保持默认构建设置即可。部署前建议先在本地运行 `npm run build`。
